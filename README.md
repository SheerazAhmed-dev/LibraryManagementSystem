# Library Management System

A console-based Library Management System developed in Java 25 by a team of three students.

## Project Overview

This project demonstrates Object-Oriented Programming, custom data structures, and algorithms through a practical library management application.

## Team Members

- **Sheeraz Ahmed** — Team Lead

## Technologies

- Java 25
- Git and GitHub
- Visual Studio Code

## Key Features

- Book and member management
- Borrowing and returning books
- Reservation management
- Transaction history
- Undo operations
- Reports and analytics

## Custom Data Structures

1. Dynamic Array
2. Singly Linked List
3. Circular Queue
4. Stack
5. Binary Search Tree
6. Hash Table

## Project Structure

- `src/` — Java source code
- `docs/` — Project architecture and technical documentation
